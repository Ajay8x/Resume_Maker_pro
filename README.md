# ResumeForge PRO (Resume Maker)

A modern, ATS-friendly interactive resume builder with multi-template support, real-time ATS optimization scoring, dynamic drag-and-drop section reordering, and PDF export.

## Features
- 5 Premium templates (Modern Pro, Two-Column Sidebar, Classic Executive, Tech Minimal, Corporate Elegant)
- Real-time ATS Score calculation and recommendations
- Drag-and-drop section & item reordering
- 1-Click Sample profiles loader
- Accent color palette & typography switcher
- Live zoom controls & A4 print optimization
